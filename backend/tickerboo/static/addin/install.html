Install TickerBoo

65+ TB.* functions for VN stock market data right inside Excel. Free forever.

1

Open Excel → Insert → Add-ins

Click Insert tab → My Add-ins → Upload My Add-in (or "Manage My Add-ins").

2

Upload the manifest URL

Paste this URL and click Upload:

Excel will validate and install the add-in. You'll see the TickerBoo button in the Home tab.

3

Start using TB.* formulas

Type any =TB. formula in a cell. Excel's autocomplete will show all available functions.

Try these first:

=TB.PRICE("VNM")
=TB.RSI("FPT", "1d", 14)
=TB.CANDLES("HPG", "1d", 20)

CANDLES spills a 20×6 table. RSI returns a single number. PRICE returns the latest close.
